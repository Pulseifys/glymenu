ГОТОВЫЙ МОД: Gly Custom Menu (Minecraft 1.21.4, Fabric)
=====================================================

ЧТО ВНУТРИ:
- Полностью свое главное меню (как на скрине):
  * тёмный фон
  * сверху: "Good to see you, <твой ник>"
  * ниже фиолетовым: "Hello Player! Good Game"
  * кнопки: Одиночная игра / Мультиплеер / Аккаунты / Настройки / Выход
  * кнопки закруглённые, полупрозрачные, фиолетовые, светлеют при наведении
- Кнопки Realms НЕТ (убраны)
- "Аккаунты" - встроенная смена ника (оффлайн-режим):
  вводишь новый ник -> "Сменить ник" -> ник изменится везде, включая меню.
  Это НЕ логин в Microsoft-аккаунты, а смена отображаемого ника (как в пиратских лаунчерах).

КАК ПОЛУЧИТЬ .JAR (выбери один способ)
=====================================================

СПОСОБ 1 - GitHub (самый простой, без консоли на твоём ПК):
1. Зарегистрируйся на github.com (если ещё нет)
2. Создай новый репозиторий (кнопка New) - назови как хочешь
3. На странице репозитория нажми "uploading an existing file"
   и перетащи ВСЕ файлы и папки из архива (можно перетащить всю папку целиком)
4. Нажми Commit changes
5. Подожди 2-5 минут, зайди во вкладку Actions -> build
6. Когда сборка станет зелёной - зайди в неё, внизу будет Artifacts -> скачай
7. В скачанном zip лежит готовый .jar  (файл БЕЗ слова sources)

СПОСОБ 2 - VS Code:
1. Установи расширения: "Extension Pack for Java" и "Gradle for Java"
2. Установи Java 21 (при первой сборке VS Code сам предложит скачать)
3. File -> Open Folder -> выбери папку проекта
4. Слева появится панель Gradle -> Tasks -> build -> build (двойной клик)
5. Жди (первая сборка долгая, 5-15 минут)
6. Готовый jar: папка build/libs/  (файл БЕЗ слова sources)

УСТАНОВКА В ИГРУ:
1. Установи Fabric Loader 1.21.4 (fabricmc.net -> use installer)
2. Установи Fabric API 1.21.4 (скачай .jar с Modrinth, кинь в mods)
3. Кинь наш jar в папку mods
4. Запускай игру
